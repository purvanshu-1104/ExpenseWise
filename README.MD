# ExpenseWise – Android Expense Tracker

## Project Overview
ExpenseWise is an Android application developed as a mini project for the Mobile Application Development course. It helps users track personal expenses, manage transactions, and monitor budgets and savings goals.

## Features
- User registration and login
- PIN lock functionality
- Dashboard overview
- Income and expense tracking
- Transaction history
- Budget management
- Savings goals
- Recurring expenses
- Reports and charts
- Profile and settings

## Technologies Used
- Java
- Android XML layouts
- Android SDK
- Room Persistence Library
- SQLite
- Gradle
- Material Components
- MPAndroidChart

## Project Structure
The Android Studio project is located in the `madproject/` folder.

- `app/` – Application source code and resources
- `gradle/` – Gradle configuration
- `Seminar/` – Seminar presentation
- `build.gradle` – Build configuration
- `settings.gradle` – Gradle project settings

## How to Run
1. Clone or download this repository.
2. Open the inner `madproject` folder in Android Studio.
3. Allow Gradle to sync.
4. Start an Android Emulator or connect an Android device.
5. Click **Run** in Android Studio.

## Database
The application uses Room with SQLite for local data storage.

## Seminar Presentation
The `Seminar/` folder contains the seminar presentation for the Mobile Application Development course.
